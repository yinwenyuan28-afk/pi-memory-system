# 用法

日常让 Cursor Agent 通过这套 **MCP 工具** 读写文件。工具读入时识别内容，写出时一律落成无 BOM 的 UTF-8。这样中文不会在保存时被静默换成 GBK。

如果 Agent 仍会调用 Cursor 自带的写入工具，再加上 README 里的 **钩子**。钩子拦住那条写入路径，让保存继续走 UTF-8。

两条路径的分工：

| 路径 | 什么时候用 |
| --- | --- |
| MCP 读写 | Agent 需要读或写项目文件时，作为默认路径 |
| 钩子 | 还要挡住官方写入工具时再加上 |

安装入口在 [安装](./install)。它管不到的编码问题在 [限制](./limits)。
