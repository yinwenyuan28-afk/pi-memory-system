# 查看与修正记忆

本地查看器帮助你理解记忆库现状，并按工作的变化修正它。

## 打开查看器

在插件仓库目录运行：

```powershell
npm run viewer
```

Windows 也可以双击 `viewers/启动查看器.cmd`。启动器同步最新页面、寻找可用端口，并打开浏览器。默认从端口 5174 开始，自动避让占用端口。

查看器与扩展使用同一个当前 profile。直接双击 HTML 文件不会加载数据，请通过启动器和本地桥打开。

::: warning 本机使用
桥默认只监听本机回环地址。目前没有鉴权，CORS 允许任意来源；开启 LAN 后访问范围会扩大。请了解这一限制，详细说明见[数据与使用边界](./limits)。
:::

## 各页面看什么

| 页面 | 用途 |
| --- | --- |
| 总览 | 数据健康与页面版本 |
| L1 记录 | 记忆内容、来源、质量、项目归属与任务状态 |
| L2 场景 | 场景块、成员、归档与整理结果 |
| L3 画像 | 正式画像、提议稿、差异与并入操作 |
| 流水线 | 排队作业、后台子代理与处理状态 |

## 修正记录与任务

内容不准确时可以纠正记录；已经完成的任务可以标记完成，需要重新做时可以重新打开。删除记录与关闭任务是不同操作。

## 审阅画像提议

先阅读提议与现有画像的差异，再决定是否并入。只有确认后的正式画像会参与后续新会话的背景。

## 处理运行状态

在流水线页查看作业是排队、运行还是结束。查看器桥使用同步 CLI，向量回填或重建等长操作可能阻塞其他请求；操作尚未返回时不要假定已经完成。
