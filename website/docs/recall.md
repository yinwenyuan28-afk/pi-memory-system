# 配置语义召回

语义召回让扩展按当前问题查找相关 L1 记录。它需要可用的 Embedding 服务和对应的本地向量。

::: info 默认状态
向量化默认关闭。自动向量化默认阈值为最近 365 天 **500 条有效 L1 记录**。配置服务、开启开关、达到阈值和已有记录回填是不同的步骤。
:::

## 配置服务和开关

在 Pi 中运行：

```text
/my-memory:model
```

按向导选择后台 LLM、设置 OpenAI 兼容的 Embedding 服务，并明确选择是否启用向量化。后台 LLM 的选择不会切换当前对话的前台模型。

修改 Embedding 配置后建议重启 Pi，使主进程和后台任务使用同一配置。已有向量表时，向导会阻止直接改成不兼容的维度；不会自动迁移向量库。

::: warning 密钥输入与保存
Pi 当前输入框不提供密码掩码，输入期间密钥可能可见；密钥保存在 profile 配置文件中。共享配置与录屏前请检查内容。
:::

## 检查已有记录

```text
/my-memory:model:peek
/my-memory:l1:embedding:list
```

检查服务配置、开关和向量数量。第二条命令用于查看未向量化的记录。

## 为已有记录回填向量

```text
/my-memory:l1:embedding:backfill
```

配置或启用向量化不会自动回填历史记录。回填会使用已配置的 Embedding 服务；服务费用由你的提供方和使用量决定。也可以在本地查看器的 L1 向量管理区操作。

## 判断是否符合预期

用一个与已保存事实明显相关的问题继续项目。召回受相关性、数量与字符预算约束，可能为空，也不保证每轮及时命中。

项目归属参与排序，当前不是严格的项目隔离过滤。要理解完整边界，请看[限制与数据说明](./limits)。
