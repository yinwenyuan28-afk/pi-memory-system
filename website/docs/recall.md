# 配置语义召回

语义召回让扩展按当前问题查找相关 L1 记录。它需要可用的 Embedding 服务和对应的本地向量。

::: tip 推荐开启向量化
如果你希望扩展能按问题的含义找回相关记忆，推荐配置 Embedding 服务并开启向量化。普通记忆提取和保存不依赖它；向量化主要让语义召回可用。作者目前使用[阿里云百炼](https://bailian.console.aliyun.com/)的向量化服务。百炼官方当前为部分文本向量模型列出 **100 万 Token 免费额度**，通常有效期为 **90 天**，仅限北京地域且受账号资格限制；模型、地域、资格和剩余额度请以[官方向量化说明](https://docs.bailian.console.aliyun.com/zh/model-studio/embedding)、[免费额度规则](https://docs.bailian.console.aliyun.com/zh/model-studio/new-free-quota)及控制台为准。
:::

::: info 默认状态
向量化默认关闭。自动向量化默认阈值为最近 365 天 **500 条有效 L1 记录**。配置服务、开启开关、达到阈值和已有记录回填是不同的步骤。
:::

## 配置服务和开关

在 Pi 中运行：

```text
/my-memory:model
```

按向导选择后台 LLM、设置 OpenAI 兼容的 Embedding 服务，并选择启用向量化。推荐开启；后台 LLM 的选择不会切换当前对话的前台模型。使用远端服务时，记忆文本会发送给你配置的服务处理，请先查看[数据与隐私说明](./data)。

修改 Embedding 配置后建议重启 Pi，使主进程和后台任务使用同一配置。已有向量表时，向导会阻止直接改成不兼容的维度；不会自动迁移向量库。

::: warning 密钥输入与保存
Pi 当前输入框不提供密码掩码，输入期间密钥可能可见；密钥保存在 profile 配置文件中。共享配置与录屏前请检查内容。
:::

## 检查已有记录

```text
/my-memory:model:peek
/my-memory:l1:embedding:list
```

检查服务配置、开关和向量数量。第二条命令用于查看未向量化的记录。

## 为已有记录回填向量

```text
/my-memory:l1:embedding:backfill
```

配置或启用向量化不会自动回填历史记录。回填会使用已配置的 Embedding 服务；服务费用由你的提供方和使用量决定。也可以在本地查看器的 L1 向量管理区操作。

手动回填不必等到自动阈值 500 条，已有少量记录也可以建立向量。`vectorization.enabled` 控制新提交记录的自动向量化；关闭它不会清除已有向量，也不会直接关闭对已有向量的召回。召回仍需要可用的 Embedding 查询服务。

## 判断是否符合预期

用一个与已保存事实明显相关的问题继续项目。召回受相关性、数量与字符预算约束，可能为空，也不保证每轮及时命中。

项目归属参与排序，当前不是严格的项目隔离过滤。要理解完整边界，请看[限制与数据说明](./limits)。

## 保存了记录却没有召回

先检查这条记录有没有向量，再检查查询是否相关。自动注入默认最多 3 条、单条正文最多 300 字符、总正文预算 2,000 字符；它不会把整个记忆库带入回答。

自动召回默认先等最多 1 秒；超时则放弃这次自动结果。异步模式不等待，结果仍属于本轮时可在后续上下文组装中插入，但单次答完的轮次可能没有机会使用它。主代理也能用 `recall_l1_records` 主动查询，默认取 5 条。

“同意”“继续”这类没有主题的短输入可能借用近期的实质讨论构造查询；没有可用主题时会跳过。尝试包含具体项目、问题和对象的问法，比反复输入“你记得吗”更便于检查效果。

参数解释见[配置说明](./configuration)，项目排序见[项目归属与记忆空间](./projects)，注入位置和历史边界见[上下文与渐进式设计](./context-design)。
