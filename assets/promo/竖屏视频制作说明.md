# Pi Memory 30 秒竖屏宣传动画

成片：[pi-memory-system-promo-vertical-zh.mp4](./pi-memory-system-promo-vertical-zh.mp4)。

规格：**1080 × 1920、9:16、60 fps、30 秒、1,800 帧**。H.264 High / Level 4.2、YUV 4:2:0 视频，AAC 48 kHz 双声道音频，MP4 带 faststart，适合手机和网页播放。

故事：旧会话里确定的支付回调排查方法，经后台整理，在新会话中按当前问题找回。Pi agent 在左、你在右，同一张带书签的方法卡贯穿整理与召回。

对话区域使用浅色背景、白色 Pi 消息和深绿色用户消息；消息宽度随文字收缩，双方采用统一的圆形字标头像。三步回复以普通消息中的编号列表呈现。

## 重新生成

需要 Windows、Python 3.11 或更高版本、FFmpeg / FFprobe，以及系统微软雅黑字体。

在 `assets/promo` 目录运行：

```powershell
python -m pip install -r requirements.txt
python render_vertical.py --prepare-audio --speech-engine windows --preview --render
```

安装依赖后也可以使用在线声音：

```powershell
python render_vertical.py --prepare-audio --speech-engine edge --preview --render
```

默认优先使用 edge-tts；在 Windows 上服务不可用时会回退到已安装的本地中文声音。2026-10-12 制作时，在线服务返回 HTTP 403，因此当前成片使用 **Microsoft Yaoyao** 中文合成声，片尾品牌名称使用 **Microsoft Zira Desktop** 英文声音。旁白没有通过音频拉伸强行塞进镜头；本地合成使用自然语速参数，每段合成后检查实际时长。

脚本优先通过 PowerShell 7 调用本地语音，系统没有 PowerShell 7 时使用 Windows PowerShell。优先选择 Yaoyao，其次 Huihui，最后 Huihui Desktop。

## 编辑与预览

- 修改旁白、字幕、对白和镜头时长：编辑 `storyboard.vertical.zh.json`。绘制中的对白布局也需对应修改 `render_vertical.py`，JSON 的 `dialogue` 字段用于记录分镜源稿。
- 修改卡片、头像、转场、字号和坐标：编辑 `render_vertical.py`。
- 主图标读取 `../icons/main-icon-d4-layer-bridges.svg`，使用超采样缩小，维持品牌几何与颜色。
- 配乐和音效由 NumPy 合成，没有使用第三方音乐素材。
- 每一帧按 `frame_index / 60` 的时间计算动画，60 fps 输出来自逐帧渲染。
- 完整旁白、配乐、音效混音经 FFmpeg 响度规范化，目标为 -16 LUFS、真峰值不超过 -1.5 dBTP。

只生成静帧和封面：

```powershell
python render_vertical.py --preview
```

已有混音时，只重新渲染画面：

```powershell
python render_vertical.py --preview --render
```

中间音频、编码日志、静帧和联系表写入系统临时目录 `pi-memory-promo-vertical-zh-20261012`。每帧通过管道送入 FFmpeg，不产生 1,800 张逐帧图片。语音和画面源稿保留在项目中，方便以后修改。

片尾已有品牌定位和完整行动信息，因此成片片尾不再叠加重复的旁白字幕；独立 SRT 保留该段字幕，供需要的发布方式使用。

## 宣传条件

这是使用示例数据的流程动画。召回镜头注明已经配置 Embedding、已为记忆建立向量；后台整理镜头通过会话推进压缩时间。视频配文应说明当前支持 Windows，并引导到网站了解完整安装、向量配置和使用限制。

片尾命令 `pi install npm:pi-memory-system` 面向已经安装 Pi 的用户。
