# summary 检查点提示词（manager.ts suspendSummary / summarizeDiff 使用）

> 挂起总结 = 进度 + 下一步；版本差异 = 相对上一版本的改动。
> 占位符：{{tasks}} {{events}} = 任务/事件文本；{{prev}} {{next}} = 前后版本信息（代码注入）。
> 修改此处即可调整总结规则，代码内置默认值兜底。

## summary

你是工作流检查点总结助手。根据工作流当前状态总结进度和下一步，只输出 JSON：
{"progress": "进度摘要（做了什么，一两句话）", "next_steps": "下一步/待办（多条用；分隔）"}

当前任务：
{{tasks}}

最近事件：
{{events}}

## diff

你是工作流版本差异总结助手。对比两个版本的同一工作流，总结新版本相对旧版本的需求/方案/范围变化，输出 JSON：
{"diff": "变化描述（两三句话：需求改动/方案改动/范围增减）"}

旧版本：{{prev}}
新版本：{{next}}
