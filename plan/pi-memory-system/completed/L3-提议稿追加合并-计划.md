# L3 提议稿追加合并 **（3/3 done）**

默认并入 `USER-temp.md` 时保留 `USER.md` 现有条目，只追加尚不存在的条目，避免完整快照被误当成增量。

## 目标与验收

- 默认合并 `USER-temp.md` 的新条目到 `USER.md`，完全相同条目去重；例如 25 条 live + 3 条新提议得到 28 条，删除数为 0。
- 查看器和 CLI 预演显示与实际写入一致的差异。
- 完整替换仍可显式选择，并保留原安全检查与写前备份。

## 范围

核心 L3 文件合并逻辑、CLI、查看器桥与 L3 页面文案和状态。

## 不做的事

- 不自动判断临时条目是否应当修改或删除稳定画像中的条目。
- 不改画像文件格式或其他层的写入流程。

## 风险/待确认
