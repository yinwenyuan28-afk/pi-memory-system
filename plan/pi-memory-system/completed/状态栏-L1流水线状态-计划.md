# 状态栏反映当前 L1 与流水线状态

将状态栏从停用旧记忆审查器的倒计时改为显示真实 L1 十轮触发计数；组合流水线进度与 Skill 审查状态，并在任务收尾后恢复摘要。

## 已确认的状态设计

- 空闲：Memory 显示 L1 剩余用户轮数；Skill 显示距离下一次技能审查的剩余轮数。
- L1 排队或运行：显示排队/耗时和子代理状态；L1 排队或运行期间计数暂停。
- L2/L3 运行：显示当前层时长，同时保留继续累计的 L1 轮数。
- Skill 审查运行或等待完整回复：显示对应状态；可以与 Memory 状态并列。
- 所有完成路径统一刷新状态，旧会话收尾不能覆盖新会话。
